# Broiler Profit Calculator - Tzaneen, Tlhabine. 

Python CLI tool for small-scale broiler farmers in Limpopo, South Africa.

I built this during my N6 Farm Management in-service training to solve a real problem: farmers guess profit, they don't calculate it.

### What it calculates
- Total feed needed
- Total cost (chicks + feed)
- Total income
- Net profit & profit per bird
- Break-even selling price
- Feed Conversion Ratio (FCR)

### Example from my farm
Input: 100 chicks @ R12.50, 4.5kg feed/bird @ R9.20/kg, 5% mortality, sell @ R75
Output: **R1942.10 profit** (R20.44 per bird)
